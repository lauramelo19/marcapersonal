# Portafolio de Laura Rocío Melo Alarcón

Sitio web personal estático en HTML, CSS y JavaScript, adaptable a móvil y listo para publicar con GitHub Pages.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html` a la raíz del repositorio.
3. Entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, guarda.
6. GitHub mostrará la URL pública cuando termine el despliegue.

## Personalización
- Edita `index.html` para actualizar textos, enlaces y secciones.
- La sección “Hobbies e intereses” se presenta como intereses profesionales porque el CV no incluye hobbies personales confirmados.
- Revisa los enlaces externos y los datos antes de publicar.
